# 08 — Prototype: how the agent looks while it plays

Type: prototype
Status: open
Blocked by: 05

## Question

What does the human see while an autonomous agent is doing its job? The POC shows a Turn through the streamed draft and one status line (ADR 0007), but a run has no Instruction to answer. Prototype the UI over a recorded or faked run from 05 and react to:

1. How the agent's **current state and intent** show ("letting the bass breathe", "building towards a drop") without covering the code or the visuals (POC ticket 17).
2. How the **Brief** is set, seen and edited.
3. How the human **starts, pauses and stops** the agent's initiative, and how that sits beside the Autonomy switch.
4. How a judgement ("that made it worse") and a revert read on screen.
5. Whether it reads as a co-performer you can play alongside, like a second DJ or VJ.
